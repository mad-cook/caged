# DefiLlama adapter

Copy `index.js` to `projects/caged/index.js` in a fork of
https://github.com/DefiLlama/DefiLlama-Adapters and open a PR.

Test inside that repo with:

```
node test.js projects/caged/index.js
```

Listing form (name, category "Token Locker"?, twitter, github, audits) is filled in the PR description;
DefiLlama requires the adapter to be merged before the protocol appears on the site.
